# 狮子养成记 · 隐藏期（桌面版 MVP）

马赛马拉，恩提亚克河边的浓密灌丛。母狮 Naramat 独自藏匿、哺育两只幼崽 8 周（56 天），然后把它们带回狮群。
游戏使用**内罗毕真实时间（EAT）**和**巢穴所在地实时天气**（坐标 -1.3756446°, 35.1500665°，Narok 郡马赛马拉，海拔约 1540 米；Open-Meteo），关掉窗口后时间照常流逝，再次打开会补算并给出"离线日记"。

## 运行

```bash
npm install   # 首次
npm start
```

- 窗口无边框、默认置顶，可拖动顶栏移动；「置顶」切换悬浮，「收起」变成一条小横条，「✕」退出（自动存档）。
- 菜单栏 🦁 图标：显示/隐藏、置顶、退出。

## 玩法

玩家不能命令狮子（遵循策划方案的产品原则），只能观察、记录、每日签到守护：

| 系统 | 说明 |
|---|---|
| 母狮行为 | 哺乳 / 理毛 / 守巢 / 正午休息 / 晨昏饮水 / 外出捕猎 / 转移巢穴，按饥饿、体力、时段自动决策 |
| 捕猎 | 夜里冲刺成功率约 30%，晨昏约 20%，白天约 8%；无月、下雨更高，游客干扰、体力差更低。100 米内潜行、30 米内冲刺，冲刺超过 60 米成功率为 0。签到可抵消白天游客干扰 |
| 花豹 | 平均捕猎成功率约 30%，夜里约 50% |
| 巢穴气味 | 驻留越久气味越重，越容易被斑鬣狗、花豹、水牛循味找到；下雨冲淡气味；母狮会主动转移巢穴 |
| 洪水 | 河水水位随巢穴坐标的真实降雨上涨、慢慢回落；短雨季（11–12 月）暴雨可能漫进低洼的河岸巢穴。母狮在场会叼着幼崽往高处跑，不在时幼崽可能被冲走 |
| 作息 | 狮子每天只活动约 3 小时、休息约 20 小时：狮群和雄狮联盟每天天黑后、黎明前各活动一段（共约 3 小时），其余时间原地休息；Naramat 出猎 2–4 小时，其余时间在巢边哺乳、理毛、守卫、休息 |
| 黑背胡狼 | 3 对，日行、领地型（各占约 900 米的草原），以食腐为主：别的捕食者在吃时在 40 米外等，没人了再捡；偶尔成对冲进瞪羚群捕汤氏瞪羚幼崽 |
| 黑面狷羚 | 转角牛羚（topi），一群 8–12 只，喜欢开阔草原，很机敏：母狮潜近时更容易被发现、冲刺成功率更低；单只母狮、花豹和斑鬣狗能捕猎，单只猎豹不能 |
| 狮群 | 4 只母狮合作捕猎、Satala 联盟 3 只雄狮巡视领地；第 5 周起狮群活动范围慢慢靠近巢穴。Naramat 饿极了会离开幼崽去狮群分食；狮群母狮靠近巢穴时，幼崽不满 6 周她一律挡回，6 周后有时让她们看一眼 |
| 流浪雄狮 | 联盟离得远时偶尔闯入领地，找到巢穴极其危险；联盟靠近会把它们赶走 |
| 非法放牧 | 每天黄昏随机决定当晚 1–2 群牛（每群 15–50 头）由牧人赶着，在天黑到凌晨之间从北边地图边缘的不同位置陆续进来，几小时后往北赶回去；食草动物和捕食者都会避开。牧人经过巢穴时母狮会转移幼崽。饿极了的母狮可能扑倒一头牛，招来牧人报复——受伤但不致死。每天签到两次：白天（6–18 点）支持日班巡护、晚上（18–6 点）支持夜班巡护，巡护车一直巡逻到换班；每次签到当天非法放牧 −20%，有巡护车值班时再 −30%。不设步行巡护，以免惊扰野生动物。巡护车发现牛群会上前劝离 |
| 六种威胁 | 斑鬣狗、花豹、雄狒狒、非洲象、非洲水牛、河马，各有活动时段与危害方式；母狮在场时会正面驱赶 |
| 成长节点 | 出生 → 睁眼(5天) → 长乳牙(14天) → 学步(21天) → 玩耍(30天) → 跟随(42天) → 靠近狮群(49天) → 第 56 天回归狮群 |
| 模式 | **纪实**：幼崽可能死亡（每只约 68% 能活过 8 周，至少一只活下来约 83%）；**守护**：会受伤挨饿但不会死 |

## 互动

- **抉择时刻**：大约每周 3 次（斑鬣狗逼近、黄昏饿了、狮群分食、河水上涨、牧人靠近），30 分钟内帮 Naramat 选；不选就按她的本能
- **每日回顾**：每天第一次打开，先看昨天草原上发生的事；日记页底部也能随时看「昨日回顾」
- **声音**：Web Audio 实时合成的河水流淌（随水位变大）、风吹树叶和草的沙沙声、虫鸣、鸟叫、风雨、母狮和幼崽的呼唤（背景声道，极低）；雄狮吼叫、斑鬣狗叫声、大象发现狮子时的号叫、黑背胡狼的叫声、清晨傍晚的鸟叫（动物叫声声道，约为背景的 3 倍）；顶栏 🔊 开关
- **巡护站问答**：每 2 小时（内罗毕时间偶数整点）出一道依据《塞伦盖蒂的狮子》（夏勒，1972）的选择题，开放到下一题；答对巡护员士气 +15，士气每小时约 −1。士气越高，巡护车发现牛群越远、开得越快、劝离越快，牧人也越不敢进来。题库在 src/quiz.js
- **勋章**：32 枚，分目击、守护、学识、抉择、成长、隐藏六类（铜/银/金）。目击类要在事件发生时开着游戏窗口，或 15 分钟内赶来——雷达上会闪烁标出「正在发生」；错过了日记里会记下。守护类勋章额外 +5 巡护士气。勋章页在右侧「🏅 勋章」
- **结局**：第 56 天的回归场景、两只幼崽的故事，以及可保存的竖版故事卡片（PNG）

## 开发

- `npm run calibrate`：无界面跑 2000 局，检查捕猎成功率与存活率
- 开发者工具里 `__ff(小时)` 或 `Cmd+Shift+F`（+6 小时）快进
- `node tools/serve.js` 后访问 http://localhost:8765 可在浏览器里预览（无置顶/收起功能）
- `npx electron tools/snap.js <目录> [js…]`：按真实窗口尺寸截图

```
main.js / preload.js   Electron 外壳（悬浮窗、托盘、收起）
src/data.js            巢穴、物种、猎物、对话文本库、生态知识
src/sim.js             模拟引擎（10 分钟一步，离线补算）
src/geo.js             巢穴周边 3.4 km 真实河道/林地/车辙路（OpenStreetMap，© OpenStreetMap contributors）
src/eco.js             生态系统：各动物群的领地、避让、捕食、抢夺猎物，与母狮捕猎联动
src/quiz.js            巡护站问答题库（依据《塞伦盖蒂的狮子》中译本整理）
src/medals.js          勋章定义、目击判定与发放
src/sound.js           声音（Web Audio 合成，无音频文件）
src/radar.js           动态雷达：读取生态模拟里的位置并绘制（箭头、猎物残骸、受伤个体）
src/weather.js         巢穴坐标实时天气 + 过去 7 天逐小时数据
src/scene.js           场景（昼夜、月相、雨、动物）：有美术素材时用图片，否则用像素画
src/art.js             美术素材加载（自动抠纯色底、裁边），素材放 src/assets/，规格见 美术素材说明.md
src/app.js             界面与主循环
```
